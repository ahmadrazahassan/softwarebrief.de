# Klarlotse illustrations

These 17 original illustrations were created with the built-in image generation tool for Klarlotse. The website uses optimized WebP files. The first 15 illustrations also have PNG source copies here.

Shared prompt direction: premium editorial business illustration; clean 2D line art; charcoal `#292d34` outlines, vivid green `#00d54b`, pale mint `#ecf9ee`, warm off-white; transparent background; no words, logos, flags, watermarks, or borrowed reference artwork.

Panorama prompt direction: original 16:9 illustrated composites of recognizable German landmarks only. The homepage version reserves pale negative space for readable copy; the footer version uses a dark skyline along the lower edge behind white links. The images are stylized composites of places in different German cities, not documentary views of one location.
